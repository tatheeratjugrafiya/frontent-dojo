# 🥋 Frontend Dojo: JavaScript (Basics to Advanced), React 18 & Tailwind CSS

> **The ultimate hands-on repository and interactive learning portal to master JavaScript from scratch, advanced asynchronous patterns, React 18, and Tailwind CSS.**

Welcome to the **Frontend Dojo**! This repository is architected for absolute beginners and experienced developers to build strong engineering fundamentals through structured notes, interactive widgets, coding challenges, quizzes, visual design studios, and full production projects.

---

## ⚡ Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start the local development server
npm run dev

# 3. Open your browser at:
http://localhost:5173
```
