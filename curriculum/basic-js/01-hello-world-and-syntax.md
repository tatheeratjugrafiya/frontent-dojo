# Module BJS-01: JavaScript Basics: Hello World, Console & Comments

## 1. What is JavaScript?
JavaScript is the programming language of the web. It makes websites interactive, responds to button clicks, handles calculations, and communicates with servers.

---

## 2. Your First Line of Code: `console.log()`
`console.log()` outputs messages or values to the browser's developer console or terminal.

```javascript
console.log('Hello, World!');
console.log(42);
console.log('Welcome to Frontend Dojo!');
```

---

## 3. Comments in JavaScript
Comments are notes written for humans. The computer ignores them during execution.

```javascript
// This is a single-line comment

/*
  This is a multi-line comment.
  It can span multiple lines.
*/
const appName = 'Dojo'; // Inline comment
```

---

## 4. Statements, Semicolons & Case Sensitivity
- JavaScript is **case-sensitive**: `username`, `userName`, and `USERNAME` are completely different variables!
- Statements are separated by line breaks or semicolons `;`.
